
# Dynamic Motion Perception in Primate Vision and Neural Networks

Source code accompanying the paper investigating how artificial neural networks and primate visual cortex process dynamic visual information during object motion discrimination tasks.

## Overview

This repository contains implementations for comparing human behavior, macaque neural recordings, and image/video-based neural networks on dynamic visual perception tasks. We analyze appearance-invariant motion coding in the primate inferior temporal cortex and identify gaps between state-of-the-art video models and biological vision systems.

## Project Structure

```
src/
├── compute_scores/    # Score computation and behavior analysis
└── plotting/          # Visualization of results and neural data
```

## Features

- **Behavior & Model Analysis**: Compute performance scores across human, neural network, and macaque datasets
- **Neural Recordings**: Tools for analyzing macaque IT cortex population activity
- **Visualizations**: Generate comparative plots of model predictions vs. neural responses

## Usage

1. Run analyses and compute alignment scores using modules in `compute_scores/`
2. Generate comparison visualizations with plotting scripts in `plotting/`
